# Web Tiket Bioskop (Tugas PPL)

Aplikasi pemesanan tiket bioskop berbasis PHP OOP + MySQL (PDO).

## Cara menjalankan

1.  Buat database di PGAdmin `bioskop`, lalu salin code di bioskop.sql dan run
4. Buka `http://localhost/bioskop/`.
