# Web Tiket Bioskop (Tugas PPL)

Aplikasi pemesanan tiket bioskop berbasis PHP OOP + MySQL (PDO).

## Cara menjalankan
1. Taruh folder ini di `htdocs` (XAMPP).
2. Jalankan Apache dan MySQL.
3. Buat database `bioskop`, lalu import `database/bioskop.sql` lewat phpMyAdmin.
4. Buka `http://localhost/bioskop/`.

## Aturan tim
- Satu orang satu branch per card, contoh: `movie-01`, `trx-01`.
- Jangan push langsung ke `main`, gabungkan lewat pull request.
- Commit pesan: `Movie-01: CRUD film backend`.
- Tiap file punya header (card, PIC, deadline). Isi nama di baris PIC.
- Beri comment penjelasan di kode penting (untuk laporan).

## Struktur
Lihat header tiap file untuk tahu tugas dan deadline-nya.
